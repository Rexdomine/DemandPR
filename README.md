# Demand PR Digital Ecosystem

Official web platform repository for Demand PR Ltd.

The project is being bootstrapped as a static-first, accessible and conversion-focused website based on the approved Demand PR Google Stitch direction.

## Status

Repository foundation and homepage vertical slice are in progress.

## Governance

- `main` is the production integration branch.
- All implementation work must use short-lived branches and pull requests.
- Do not commit API keys, `.env` files, customer enquiry data or private design credentials.
- Pull requests must pass the documented lint, type-check, test and build gates before merge.
